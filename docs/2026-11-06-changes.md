## 二、Tabbar 布局与描边

文件：`components/bottom-tab-bar.vue`

- 5 个图标不再整体等分：
  - 发布按钮固定宽 `100rpx`，左右各留 `10rpx` 间距，不参与横向等分。
  - 其余 4 个 tab 均分剩余宽度，左侧 2 个、右侧 2 个，每个图标在自己的区域内居中。
  - 选中态背景宽度等于单个 tab 区域，即「半边宽度的一半」。
- 移除了原有的整体 `gap: 16rpx`（保留注释），避免左右分布不对称。
- 修复首尾选中态盖住底栏描边的问题：
  - 底栏内边距为 `4rpx 2rpx`。
  - tab 高度由 `100rpx` 调整为 `92rpx`，使选中背景上下不压住 2rpx 的内阴影描边。
- 发布按钮保持正圆、固定尺寸，并仅通过 `translateY` 向上突出。

## 四、登录拦截组件复用

新增文件：`components/login-guard.vue`

组件封装内容：

- `ensureLogin(options)`：已登录返回 `true`；未登录弹出登录提示并返回 `false`。
- `open(options)` / `close()`：手动控制登录提示弹窗。
- `isLoggedIn()`：校验本地 token 是否存在且未过期。
- `clearLoginCache()`：清理 token、userId、username、userInfo、squads。
- token 过期时自动清理缓存，并展示「请重新登录」提示。
- 支持按调用场景覆盖：标题、文案、确认/取消按钮文案、是否显示取消按钮、登录页跳转方式。

已迁移的登录拦截位置：

| 文件 | 场景 |
| --- | --- |
| `components/home-activity-card.vue` | 收藏、立即报名 |
| `src/activity-detail/activity-detail.vue` | 收藏、报名 |
| `src/create-activity/create-activity.vue` | 进入页面拦截（redirectTo）、发布前拦截（navigateTo） |
| `components/bottom-tab-bar.vue` | 底栏发布 |
| `components/moment-feed.vue` | 点赞、评论、发布等需登录操作 |
| `pages/user/user.vue` | token 过期提示 |
| `pages/user/components/user-squad-panel.vue` | 创建小队、查看小队详情 |

说明：`api/http.js` 中的接口级登录拦截仍使用原生 `uni.showModal`，属于网络层兜底，不在页面层组件内。

## 五、「我的」页入口与未登录态

文件：`pages/user/user.vue`、`pages/user/components/user-quick-entry-panel.vue`、`pages/user/components/user-squad-panel.vue`

- 快捷入口改为父级统一处理：
  - `UserQuickEntryPanel` 不再直接 Toast，而是向父级 `$emit('select', item)`。
  - 发布活动：登录拦截通过后跳转 `/src/create-activity/create-activity`。
  - 管理小队：登录拦截通过后跳转首个已加入小队的详情页；无小队时提示「请先创建小队」。
  - 活动数据、收益明细仍保留「功能开发中」Toast。
- 未登录时底部操作：
  - 「退出登录」位置改为「去登录」，复用同一 `.logoutCard` / `.logoutText` 样式。
  - 点击调用 `goLoginPage()`，与登录弹窗、用户名入口一致，均跳转 `/src/login/login`。
- 小队管理空白修复：
  - 未登录时 `items` 为空，空白并非占位卡片，而是空的横向 `scroll-view` 加头部下边距。
  - 无小队时不再渲染 `scroll-view`。
  - 头部增加 `.squadHeader--empty`，空状态下移除 `22rpx` 下边距。
  - 「小队管理」标题与「点击创建新小队」入口保留。
