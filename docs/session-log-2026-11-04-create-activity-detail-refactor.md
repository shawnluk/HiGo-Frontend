## 一、会话概览

关键背景：

- 主题主色为红 `#ff3b30`，辅助渐变橙红 `#ff6a5c → #ff3b30`。
- 页面底色统一为浅灰 `#f5f5f6`，卡片为纯白 + 32rpx 圆角 + 中性浅投影。
- 全局 mock 由 `config/env.js` 的 `useMock` 控制，本次未涉及。
- 后端「活动类型」接口已存在；小队列表接口尚未提供。

## 二、创建活动页 `src/create-activity/create-activity.vue`

### 1. 主题配色改造

- 面板底色由紫蓝渐变改为纯浅灰 `#f5f5f6`，阴影改为中性黑。
- 卡片由渐变改为纯白 + 32rpx 圆角 + 浅投影。
- 区块标签、页头装饰线、收费单位、插入图片按钮、发布按钮统一为主题红系。
- 输入控件改为浅灰底 `#f7f7f7` + 中性描边，去掉彩色投影；文字层级分为 `#1f1f1f`、`#333333`、`#b3b3b3` / `#999999`。

### 2. 封面上传框

- 按设计稿改为斜向三段渐变 `#ffa271 → #f2607a → #9b5ce0`（135deg）。
- 去掉原红色虚线描边；已有封面时改用浅投影区分。
- 保留白圈相机图标与白色提示文字。

### 3. 活动详情区域结构化重构

最终结构（自上而下）：

1. 区块标识「活动详情」：`sectionHead sectionHeadOuter` + `sectionTag`，样式与「活动封面」「活动介绍」一致，位于卡片上方。
2. 卡片一：`所在小队` + `发布圈子`（两行，中间 1rpx 分隔线）。
   - 所在小队为占位行，右侧灰字「请选择你的小队」+ `›`。
   - 发布圈子沿用原 `picker`（`typeOptions` / `onTypePickerChange`）。
3. 卡片二：`活动名称` + `活动时间` + `活动地点`（三行分隔）。
   - 活动时间行下保留「选日期 / 选时刻」两个胶囊按钮（`onDatePickerChange` / `onTimePickerChange`）。
4. 卡片三：`门票与人数`（见下节）。
5. 卡片四：`活动介绍`（原 editor + 插入图片按钮，未改）。

样式要点：

- `rowCard` 覆盖卡片内边距为 `0 28rpx`，同时关闭 `::before` 红色光斑。
- `rowLine` 行高 104rpx；`rowLabel` 28rpx/500/`#1f1f1f`；`rowInput` 右对齐、透明底；`rowValue.isPlaceholder` 灰色。
- `rowDivider` 1rpx `#f0f0f0`。
- 删除旧的「标签 + 灰色输入框」样式类（`field` / `fieldInput` / `fieldSelect` / `timePickRow` / `locPin` 等），避免遗留死代码。

### 4. 门票与人数卡

- 卡头「门票与人数」30rpx 加粗。
- 免费 / 收费切换：浅灰轨道 + 左右等宽两项，选中项红底白字。
- 人均票价：仅「收费」时显示，左标签 + `¥` + 右对齐数字输入，仍绑定 `activityForm.fee_note`。
- 人数上限：固定展示「20 人」，免费/收费两种模式下常显，纯展示、不参与提交。
- 新增 `feeMode` 与 `setFeeMode`：
  - 选「免费」→ `fee_note = '0'`；
  - 选「收费」→ 若当前为 `'0'` 则清空待填。

### 5. 底部操作栏

- 左侧新增「存入草稿」按钮，右侧发布按钮占满剩余宽度。
- `saveDraft`：把当前表单、日期/时刻选择、封面临时路径与保存时间写入本地缓存 `hiGoActivityDraft`，成功/失败均有 toast。
- 高度与间距调整：上下内边距 20rpx，按钮高 84rpx，背景透明（沿用页面浅灰底），去掉分割线与渐变底色。
- 滚动区高度改为实测：
  - `updateScrollAreaHeight` 在 `onReady` 时测量抓手条、页头、页脚真实高度后计算；
  - 兜底估算 310rpx；`onReady` 100ms 后重测一次；
  - `.sheetScroll` 增加 `flex: 1; min-height: 0`，避免 footer 被挤出可视区。
- 按钮下方留白 20rpx + 安全区（`env(safe-area-inset-bottom)`）。

## 五、遗留与注意事项

- **小队选择**：创建活动页「所在小队」目前仅为占位，点击触发 `onPickSquad` 提示「小队列表暂未开放」；后端小队列表接口接入后，替换为 `picker` 数据源即可，未新增提交字段。
- **人数上限**：固定 20 人仅为设计稿展示，接口无对应字段，暂不提交。
- **草稿**：仅本地保存，未实现进入页面自动回填；如需可补充读取 `hiGoActivityDraft` 的逻辑。
- **活动费用模式**：`feeMode` 为前端展示态，提交仍沿用原 `fee_note` 字段。
- 建议后续在 H5 与小程序端分别验证：卡片分隔线、右对齐输入（小程序 input 的 `text-align` 兼容性）、底部安全区留白。
