## 二、创建小队页 `src/create-unit/create-unit.vue`

### 1. 页面结构重构

- 顶栏改为自定义：返回箭头 + 「创建小队」标题，状态栏由 `var(--status-bar-height, 50rpx)` 避让。
- `pages.json` 中该页 `navigationStyle` 由 `default` 改为 `custom`。
- 页面采用 `position: fixed` 全屏 flex 布局：顶栏 → `scroll-view` 表单区（`flex: 1; height: 0`）→ 底部操作栏。

### 2. 表单卡片

自上而下：

| 区块 | 说明 |
| --- | --- |
| 小队头像 | 渐变圆角方块 `#ffa271 → #f2607a → #9b5ce0`，右下角红色相机角标，下方文案「上传小队头像」 |
| 小队名称 | 左标签 + 右对齐输入，保留原有非法字符过滤、16 宽度截断、输入缓存与 `key` 重建逻辑 |
| 小队简介 | 卡片内标题 + 多行 `textarea`，保留 100 字限制 |
| 小队分类 | 3 列宫格，复用分类接口的 `category_id / category_name / icon`，选中项红色描边高亮，末位「更多」为占位提示 |
| 所在城市 / 入队审核 | 合并卡片：城市使用 `picker mode="region"`（H5 条件编译降级为提示），审核使用原生 `switch`（红色） |
| 底部按钮 | 通栏红色胶囊「创建小队」，底部叠加安全区 |

### 3. 返回逻辑修复

原实现无页面栈时 `uni.switchTab('/pages/user/user')` 报错：

```
switchTab:fail can not switch to no-tabBar page
```

原因：项目未配置原生 tabBar，`/pages/user/user` 不是 tabBar 页。改为：

- 有页面栈：`uni.navigateBack()`
- 无页面栈：`uni.reLaunch({ url: '/pages/index/index' })`

## 四、底栏发布入口 `components/bottom-tab-bar.vue`

### 1. 交互流程变更

原流程：点击发布 → 登录校验 → 吐泡泡 3s → `redirectTo` 发布活动页。

新流程：点击发布 → 登录校验 → 吐泡泡 1.5s → 底部弹出「发布」面板 → 点击面板入口跳转对应创建页。

### 2. 发布面板

按 `unitone-ui/发布.png` 实现：

- 半透明遮罩 + 底部上滑白色面板（顶部 28rpx 圆角、拖拽条）。
- 头部：左侧标题「发布」，右侧圆形关闭按钮。
- 三个入口卡片（图标底色按设计稿区分）：

| 入口 | 副标题 | 图标底色 | 跳转 |
| --- | --- | --- | --- |
| 发布活动 | 创建线下活动 | 粉色 `#ffe9e6` | `/src/create-activity/create-activity` |
| 发布动态 | 图文记录出行 | 紫色 `#efeafd` | `/src/create-moment/create-moment` |
| 创建小队 | 成为队长 | 绿色 `#e7f8ec` | `/src/create-unit/create-unit` |

- 底部灰色「取消」按钮。
- 点击遮罩、关闭按钮、「取消」均可关闭；选择入口后先关闭面板，再用 `navigateTo` 跳转（返回可回到当前 tab 页）。

### 3. 气泡动画时长（最终 1.5s）

- 单个气泡 `animation-duration: 1.1s`。
- 6 个气泡延迟：0 / 0.06 / 0.12 / 0.2 / 0.28 / 0.4s，最后一个气泡在 1.5s 结束。
- 定时器 `setTimeout(..., 1500)` 与 CSS 时长保持一致，气泡吐完立即弹出面板。
- 修改时长时需同步调整 CSS 动画时长、各气泡延迟与定时器三处。
